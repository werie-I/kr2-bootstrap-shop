
# Чайный клуб

## Контрольная работа №2

### Практическая работа №9

**Тема:** Bootstrap-сетка: container, row, col-* и базовая структура страницы.

## Описание проекта

Сайт чайного клуба предназначен для знакомства с чайной культурой, сортами чая и мероприятиями клуба.

## Структура сайта

- `index.html` — главная страница.
- `tea.html` — чайная карта.
- `events.html` — мероприятия.
- `about.html` — информация о клубе и контакты.

## Используемые технологии

- HTML5
- CSS3
- Bootstrap 5.3.3
- Адаптивная сетка Bootstrap

## Реализованные элементы

- Шапка сайта с навигацией.
- Главный экран с текстом и изображением.
- Блок преимуществ клуба.
- Карточки популярных сортов чая.
- Блок приглашения на мероприятия.
- Подвал сайта.
- Адаптивная сетка с использованием `container`, `row` и `col-*`.

## Запуск проекта

Откройте файл `index.html` в браузере.
