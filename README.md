# Чайный клуб

Учебный проект интернет-магазина чая, созданный с использованием HTML, CSS и Bootstrap 5.

## Страницы проекта

- index.html — главная страница.
- catalog.html — каталог товаров.
- product.html — страница товара.
- order.html — форма оформления заявки.

## Используемые технологии

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons

## Реализованные компоненты Bootstrap

- Навигационная панель (Navbar).
- Карточки товаров (Card).
- Кнопки (Button).
- Значки (Badge).
- Уведомления (Alert).
- Формы (Form).
- Модальные окна (Modal).
- Аккордеон (Accordion).
- Адаптивная сетка (Grid).

## Запуск проекта

Открыть файл index.html в браузере.
